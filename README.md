# 🏪 Análise de Desempenho das Lojas — Challenge Data Science

## 📘 Descrição do Projeto

Este projeto tem como objetivo **analisar o desempenho de quatro lojas** a partir de uma base de dados de vendas.  
A análise utiliza **Python (Pandas, Matplotlib)** e responde a uma questão estratégica:  
➡️ **Qual loja deve ser vendida, considerando desempenho, satisfação do cliente e eficiência operacional?**

Com base nas análises realizadas, foi **recomendada a venda da Loja 4**, por apresentar **baixo faturamento, avaliações negativas e altos custos logísticos**.

---

## 🎯 Objetivos da Análise

1. Calcular **faturamento total** por loja.  
2. Analisar **vendas por categoria de produto**.  
3. Calcular **média de avaliação (NPS)** por loja.  
4. Identificar **produtos mais e menos vendidos**.  
5. Calcular **frete médio** por loja.  
6. Criar visualizações:  
   - Barras e empilhadas  
   - Boxplots  
   - Gráficos de dispersão  

8. Elaborar **relatório conclusivo** com recomendação de venda.
